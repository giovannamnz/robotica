# robotica  
Projeto de Robótica / Automação  
Aluno: Giovanna Menezes  

## Descrição  
Este repositório reúne diversos **exercícios de programação em C++** voltados para robótica ou automação de hardware, desenvolvidos no curso de Robótica realizado pela Secretária do Desenvolvimento.  
Os arquivos atuais contemplam práticas com LED, botões, foto-resistor, potenciômetro, servo, etc.

## Estrutura do Projeto  
| Arquivo                           | Descrição                                       |
|-----------------------------------|-------------------------------------------------|
| `ligando_led.cpp`                 | Acende um LED simples                           |
| `ligando_led_botao.cpp`           | LED controlado por botão                        |
| `ligando_led_em_cadeia.cpp`       | Sequência de LED’s acendendo em cadeia          |
| `ligando_led_fotoresistor.cpp`    | Controle de LED via foto‐resistor               |
| `ligando_led_poteciometro.cpp`    | Controle de LED via potenciômetro               |
| `servo.cpp`                       | Controle de servo motor                         |

## Requisitos  
- Placa compatível (por exemplo Arduino ou similar)  
- Ambiente de desenvolvimento C++ configurado para microcontrolador (ex: Arduino IDE)  
- Biblioteca suportada para servo (quando aplicável)  
- Fonte de alimentação e conexão com o hardware correspondente
